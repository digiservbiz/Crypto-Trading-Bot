# Security Policy

## Supported versions

The master branch is the primary supported development line.

## Reporting a vulnerability

Do not open a public issue for an undisclosed security vulnerability.

Report suspected vulnerabilities privately through GitHub's private vulnerability reporting/security advisory mechanism.

Include:
- affected file and version/commit
- reproducible steps
- security impact
- any suggested mitigation

Never include exchange API keys, private keys, seed phrases, access tokens, or other credentials in a report.

## Trading-safety rule

This project is not considered safe for funded live trading unless the exchange execution layer, position reconciliation, kill switch, and testnet/paper-trading validation have been completed.
